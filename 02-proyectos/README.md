## Qué debe contener cada proyecto

Cada carpeta tendrá un README con problema, alcance, estado, requisitos, procedimiento, pruebas, evidencias y conclusiones. El código y otros documentos se añadirán cuando se desarrollen.

Las animaciones y capturas recreadas son material explicativo. Las evidencias de ejecución deben identificarse por separado y revisarse antes de publicarse.
